# EVAT - Écosystème Universel de la Vie et des Métiers
Piloté par ELAWS (Assistant intelligent souverain).

## Description
Application web modulaire et souveraine pour la gestion des corps de métier (Artisanat, Agriculture, Sécurité).

## Utilisation
1. Décompressez l'archive ZIP.
2. Vous obtenez le fichier `index.html`.
3. Importez-le sur votre dépôt GitHub.
4. Déployez-le sur Vercel.
